# Informatic_lab

## О проекте
Проект представляет собой приложение для учёта подписчиков журнала. Система предназначена для регистрации, систематизации и обработки обратной связи пользователей, а также публикации электронных версий выпусков.

В системе предполагается хранение следующих данных о подписчиках: возраст, пол, метки
интересов, список понравившихся публикаций (выпусков), email (прл наличии),
Возраст и пол используются для формирования статистической отчётности, В совокупности с
метками интересов и историей реакций (понравившиеся публикации) эти данные служат
основой для изучения аудитории и персонализации рекомендаций.
Для подписчика это может означать более релевантную подборку материалов в рамках
редакционной политики издания. Для отдела аналитики данные позволяют точнее
сегментировать аудиторию и оценивать её предпочтения.

## В системе выделяются две основные роли пользователей:
1. подписчик журнала;
2. сотрудник отдела аналитики либо ответственный за публикацию контента (как правило,
задачи по сбору данных и работе с аудиторией выполняют младшие сотрудники или
контент-менеджеры).
Аутентификация подписчиков и сотрудников реализуется через логин и пароль

## Функционал системы:
### Для подписчика:
Личный кабинет с отображением персональных данных (возраст. пол, метки интересов,
emai]).
Возможность редактирования данных и удаления аккаунта (кнопки «Изменить данные»,
«Удалить аккаунт»),
Страница выпуска: просмотр электронного экземпляра, оценка, отзыв.
Блок пожертвований на нужды журнала (интеграция платёжного виджета)„
### Для сотрудника (аналитик / публикатор):
Панель аналитики: половозрастная пирамида подписчиков, диаграмма интересов,
топ-дыпуски по оценкам и отзывам.
Управление выпусками: загрузка/выгрузка, редактирование, удаление (кнопки
«Изменить», «Удалить»).
Публикация выпуска (кнопка «Опубликовать выпуск»).
### Общие механизмы:
Регистрация и авторизация (отдельные формы для подписчиков и сотрудников с
разграничением прав доступа).
Сбор и хранение данных о пользователях и их действиях (оценки, отзывы,
пожертвования).
Представление данных в виде отчётов и графиков для аналитики.

## Архитектура и стек:
• Архитектура: четырёхуровневая (интерфейс / бизнес„логика / слой доступа к данным
хранилище).
• Язык: Python З. Л 1.
• Хранение данных: SQL (SQLite)
Формат обмена данными: JSON

- [Git]

## Запуск проекта

1. Клонирование репозитория с github
```bash
git clone https://github.com/kosterik/TechSupport.git
```

2. Переход в корень проекта
```bash
cd TechSupport
```

3. Создание виртуального окружения
- **Windows**
```bash
python -m venv venv
```
- **Linux/macOS**
```bash
python3 -m venv venv
```

4. Активация виртуального окружения
- **Windows**
```bash
venv\Scripts\activate
```
- **Linux/macOS**
```bash
source venv/bin/activate
```

5. Установка зависимостей
```bash
pip install -r requirements.txt
```

6. Запуск работы
- **Windows**
```bash
python src/techsupport/main.py
```
- **Linux/macOS**
```bash
python3 src/techsupport/main.py
```

После запуска программа выведет:
```text
hello world
```
